> “嗯？爱？啊，当然，当然。前几天便利店还在卖呢。” —— 八九寺真宵

在《伪物语》的这段对话里，一份“爱”的价格是 298 日元。

八九寺真宵、忍野忍和斧乃木余接分别有 $A$、$B$、$C$ 日元零花钱。三人决定把零花钱放在一起，购买尽可能多份“爱”。每份必须完整购买，不能购买不足一份的部分。

请计算她们最多能买多少份“爱”。

# 输入格式 {#input}

输入一行，包含三个整数 $A,B,C$，依次表示三人的零花钱。

# 输出格式 {#output}

输出一个整数，表示最多能购买的完整份数。

# 数据范围 {#constraints}

$0\le A,B,C\le 10^{18}$。

::: {.samples}
``` {.input}
100 100 100
```

``` {.output}
1
```

``` {.input}
297 0 0
```

``` {.output}
0
```

:::

# 样例说明 {#explanation}

第一组样例：三人共有 300 日元，可以购买一份“爱”。

第二组样例：三人共有 297 日元，不足以购买一份“爱”。
