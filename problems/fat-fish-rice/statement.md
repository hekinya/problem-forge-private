# 大肥鱼买白饭

## 题目描述

在很深很深的数据海底，住着一条蓝色大肥鱼：deepseek。

deepseek 的工作，是把整片语料海里的文字一口吞下去，再一句一句吐出来。它吐出的每一段文字都会被换算成 token，记进它的钱包。所以对 deepseek 来说，token 既是工资，也是饭钱。

最近，深海食堂新开了一个「白饭档口」：一碗热气腾腾的大白饭，标价 $19$ token。档口生意很好，队伍排得很长，deepseek 每次都挤不过那些小虾米，只好在旁边等自己的鱼鳍够长。

今天 deepseek 终于攒够了勇气，也攒下了一些 token。它的钱包分成两格：

- 上面一格装着「10 token 大礼包」，每个礼包里有 $10$ 个 token，一共有 $a$ 个；
- 下面一格装着零散的 token，散 token 要用鱼鳍一个一个抓，一共只有 $b$ 个。

档口只卖整碗，不卖半碗，也不许赊账。deepseek 想知道：凭钱包里现有的这些 token，它最多能买到几碗大白饭？

## 输入格式

一行两个整数 $a$ 和 $b$，分别表示「10 token 大礼包」的个数和散装 token 的个数。

## 输出格式

输出一行一个整数，表示 deepseek 最多能买到的白饭碗数。

## 数据范围

对于全部测试点，保证：

- $0 \le a \le 10^4$
- $0 \le b \le 9$

## 样例 1

输入：

```text
10 3
```

输出：

```text
5
```

样例说明：$10$ 个大礼包一共 $10 \times 10 = 100$ 个 token，再加上 $3$ 个散装 token，钱包里共有 $103$ 个 token。一碗白饭 $19$ token，买 $5$ 碗一共花掉 $95$ 个 token，还剩 $8$ 个 token，不够再买一碗，所以最多能买 $5$ 碗。
